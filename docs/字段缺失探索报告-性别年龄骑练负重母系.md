| 形态 | PDF 实文 | 后果 | 例子 |

## 三、「有的比赛有性别、有的没有」的机制（智利）

- volante **不逐马印性别**（对 PDF 全文 grep 过：无 M/H 字母列、无 (M)/(H) 后缀；智利用让磅制，性别信息隐含在 hándicap índice 里）。
- `src/collect-sources.js` 链路里 `src/backfill-sa-ped.js` 用 `sexFromConditionEs()`（`src/sources/normalize.js:143`）从**赛事条件文本**推断性别，整场统一打标：
  - 2R 条件 `CONDICIONAL PARA HEMBRAS DE 3 AÑOS…` → 全场牝 ✅
  - 8R 条件 `CONDICIONAL PARA CABALLOS DE 4 AÑOS Y MAS…` → 全场牡 ✅
  - 10R `PARA MACHOS Y HEMBRAS`（混合）→ 正确留空 ✅
  - 其余 12 场是 `HANDICAP Xa. Serie`（índice 混性别让磅）→ 无性别词，整场留空 ← **截图两场即属此类**
- 所以「有的场缺性别、有的缺年龄、有的都缺」= 性别是**场级**信息（源不印），年龄是**马级**信息（源印了但被解析丢）——两者缺失模式自然不同步；混性别组里的合并行马匹就「都缺」。

CHC 版式（PDF 核对：`https://teletrak.cl/wp-content/uploads/2026/11/102182-1.pdf`）：每马本应是 `名(父) / 毛色字母 / 年龄 / kg 骑师 / 练马师`，但**毛色字母经常整行缺席**（SONRIELE、LA RECAUDADORA、EL CATIMBA、SIMONE BULL 都没有；LA JOSITA 那行是 `R-15`）——`chc` 解析按 `body[2]=年龄` 固定取位，毛色行一缺年龄就错位 → CHC 年龄缺 66%。

CHS 版式条件文本带性别词的比例较高，所以只有 15% 缺性别。

## 四、其他源的归因

### 1. 澳大利亚 ra（`https://www.racingaustralia.com.au` Form.aspx）
- **性别缺 26.7%（465 头）—— 全部是同一个解析 bug**。RA 资料块是 `4 year old bay or brown gelding (17-10-2022)` 一句话；`parseProfileDesc()`（`src/sources/racingaustralia.js:94-104`）的 `SEX_WORDS` 里混进了毛色词 `"brown"`，而 `words.find()` 按描述语序取第一个命中词 → 凡描述含 "brown"（`bay or brown gelding` / `brown mare`）性别都解析成 "brown"，再经 `SEX_JP` 映射回 null。统计确认：465 头缺失里 **464 头 sexRaw 正是 "brown"**。修复=性别词搜索剔除毛色词，一行改动，可救回全部 465 头。
- **骑师缺 9.5%**：抽查全部落在每场编号靠后的「替补/紧急参赛」段（如 WF 4R#10、QLD 2R#4…），RA Form 页对这些马本来就不给骑师（Rider not declared）——源侧没有，无法改。
- **父父 100% 缺**：Form 页只有 Sire/Dam/母父（无父父）；已有 `KNOWN_SIRE_OF_SIRE` 兜底表只覆盖重点种公马。保持现状即可。

### 2. 新西兰 lv（`https://loveracing.nz`）
- **11-18 SC（results 阶段）24 头全缺性别/年龄/负重/母系名**：`loveracing.js:620-624` 在「全场都是 results 阶段」时跳过 EntryDetail 模态富化（当年为省请求做的取舍），results 表格本身无性别/年龄列。模态 URL 其实每头都有（`lv.line.entryUrl`）。
- **负重 100% 缺**：NZ 的 weight/barrier 只在赛日晨 fields 阶段表格出现（提前 2 天的 fields-download 阶段页面没有）——源阶段限制。
- **骑师缺 9 头（11-20 Taranaki）**：这 9 头模态已抓到（gear 字段齐全），是源侧骑师未宣布（赛前 3 天）——无法改。

### 3. 巴西 tol（`https://www.turfeonline.com.br/programas`）
- 练马师缺 67.9%：TurfeOnline 全文页本来就没有练马师；练马师唯一免费源是 JCB「Programa com Retrospecto」PDF，但只覆盖 Gávea 且新闻列表只留最新一期 → 非 Gávea 场与历史场次补不上。性别/年龄/父母缺 11-12% = ABCPCC 血统回填的同名/缺登记残留。源侧限制为主。

### 4. 阿根廷 / 土耳其 / 日本 / RP
- si / lp / tjk / jra 基本满字段。rp 父父缺 26.9%、母父缺 4.7%（Racing Post 部分马页不列父父），属源侧，已有兜底表可渐进补。

### 5. 智利母系/母父：源侧「真缺口」
- Teletrak volante 只印父系（Padrillo）。智利官方 Stud Book `https://www.studbookdechile.cl/` 11-17 时 DNS 不解析，本次复测 **DNS 已能解析（190.196.77.252）但 upstream connect 超时**，仍不可用 —— 有恢复迹象，值得加一个每日探针，一旦通了就照 ABCPCC/SBA 模式补 母/母父/父父。
- `http://fspedigreechile.cl/` 只是新闻/链接站（Google Sites），无结构化血统库。
- Equibase International（`https://www.equibase.com/static/foreign/entry/index.html`）本可逐马给性别+年龄做智利交叉回填，本次实测仍被 Incapsula 拦（返回 "Pardon Our Interruption" 挑战页）——需要境外出口 + 浏览器 UA，自动接入不现实，保持人工查阅定位。

### CI OCR 支持结论

GitHub Actions `ubuntu-latest` **可以支持 OCR**：`sudo apt-get install -y tesseract-ocr tesseract-ocr-spa`（西班牙语包）即可，约 +30-60s 装机时间。当前 Teletrak volante 是文字型 PDF（PyMuPDF 直接抽文即可），OCR 仅在站方改用扫描件/图片 PDF 时才需要 —— 可在 `pdftext.py` 加兜底：抽文结果过短时自动走 tesseract。暂不默认启用（CI 保持零系统依赖，装机提速）。
